# 🌐 Recurso 3 — **Hackerrank, OmegaUp y Clean Code**

---

## 📄 Descripción General

En este recurso exploramos **tres herramientas esenciales** para mejorar las habilidades de programación y la calidad del código:

- **Hackerrank:** plataforma global de retos y concursos de programación.  
- **OmegaUp:** plataforma educativa latinoamericana para practicar programación competitiva.  
- **Clean Code:** conjunto de principios para escribir código claro, ordenado y fácil de mantener.

Este recurso sirve como apoyo práctico para reforzar las habilidades de programación que estamos adquiriendo en la Unidad 2.

---

# 🔹 1. Hackerrank

### 🌍 ¿Qué es Hackerrank?

Es una plataforma internacional donde los estudiantes y profesionales practican habilidades de programación mediante ejercicios, retos y concursos.  
Permite fortalecer la lógica, aprender nuevos lenguajes y prepararse para entrevistas técnicas de empresas reales.

### 🎯 Características principales

- Problemas desde nivel básico hasta avanzado.  
- Retos en múltiples lenguajes (C, Python, Java, etc.).  
- Casos de prueba automáticos.  
- Tablas de clasificación globales.  
- Secciones temáticas (algoritmos, estructuras de datos, matemáticas, etc.).

### 🔗 Enlace oficial  
👉 **[https://www.hackerrank.com/](https://www.hackerrank.com/)**

---

# 🔹 2. OmegaUp

### 🇪🇨 ¿Qué es OmegaUp?

Es una plataforma muy utilizada en Latinoamérica, especialmente en Ecuador y México, para aprender y practicar programación competitiva.

Ha sido diseñada para estudiantes que desean:

- Practicar problemas algorítmicos.  
- Participar en concursos.  
- Prepararse para olimpiadas de programación.  
- Mejorar sus habilidades en lógica computacional.

### 🎯 Características

- Problemas con retroalimentación inmediata.  
- Concursos públicos y privados.  
- Rutas de aprendizaje.  
- Ranking de usuarios.  
- Soporte para múltiples lenguajes.

### 🔗 Enlace oficial  
👉 **[https://omegaup.com/](https://omegaup.com/)**

---

# 🔹 3. Clean Code

### 🧼 ¿Qué es Clean Code?

"**Clean Code**" es un conjunto de buenas prácticas para escribir código que sea:

- Fácil de leer  
- Fácil de modificar  
- Fácil de mantener  
- Libre de redundancias  
- Claramente estructurado

Estas prácticas son utilizadas por profesionales en la industria del software para mejorar la calidad de los programas.

### 🧠 Principios básicos del Clean Code

- **Nombres claros y descriptivos**  
  Variables, funciones y clases deben indicar claramente su propósito.

- **Funciones cortas y específicas**  
  Cada función debe hacer solo una cosa.

- **Evitar duplicación de código**  
  Lo repetido debe convertirse en funciones o estructuras reutilizables.

- **Comentarios necesarios, no obvios**  
  Documentar “por qué” se hace algo, no “qué hace”.

- **Formato limpio y consistente**  
  Identación, espacios y saltos de línea adecuados.

### 📘 Importancia del Clean Code

Aplicar estos principios ayuda a:

- Reducir errores  
- Facilitar el mantenimiento  
- Mejorar el desarrollo en equipo  
- Crear programas profesionales
